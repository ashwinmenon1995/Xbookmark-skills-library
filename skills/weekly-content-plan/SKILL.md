# Weekly content plan

Propose post ideas from the user's private library. Do not publish them.

## Limits

- Do not post, send, pay, sign up, or delete unless the user explicitly tells you to do that specific thing.
- The plan is private. Never commit it to this repo.
- Do not invent a platform list. Use only platforms the user chooses.
- Every idea cites a real entry id from `my-skills.md`. If the library has no entries, say so and stop.

## Private folder

`~/bookmark-library/` unless the user named a different folder outside this repo.

## Steps

1. Ask which platforms to plan, unless the user already named them in this conversation. Examples they might choose: X, Instagram, LinkedIn. Confirm the list before you write ideas.
2. Read `~/bookmark-library/my-skills.md`. If `~/bookmark-library/what-works-for-me.md` exists, read it and prefer patterns it says worked. Do not copy that private file anywhere else.
3. Copy `templates/content-plan.template.md` to `~/bookmark-library/content-plan-YYYY-MM-DD.md`.
4. For each chosen platform, propose 3–5 post ideas. Each idea names the platform, the angle, and one library entry id it comes from. If a second entry also applies, cite that id too.
5. Leave draft status as not drafted. Do not write the posts, schedule them, or put them in a publishing tool.
6. Show the plan to the user.
